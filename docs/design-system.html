A dark, wet, glowing workshop. Liquid is the only luminous thing on screen; everything else is layered slate and steel. Brass marks what you can touch.

Game

Pipe sections

Every section is drawn procedurally from the same layer recipe: shadow, body, bore, liquid, flanges. Liquid is a stroke on the same path clipped by progress, so the fill animation is free. All eight sections plus the fixed cells:

Layer recipe

Sizes are relative to cell size c. Body 0.36c · bore 0.25c · liquid 0.21c · flange 0.10c long. Round joins give the elbow for free.

Cross bridge

The horizontal body is drawn over the vertical one with a 0.05c surface.deep gap around it, so it reads as two independent channels. Each channel has its own liquid layer.

Reservoir tank

Violet tank, aqua liquid. The tank fills bottom-up during progress 0.1–0.9. The hourglass badge marks it as slow even for colour-blind players.

Head & bubbles

The active segment glows 16dp in liquid.glow; two or three bubbles drift up behind the head. Filled segments keep a faint top highlight.

Layout rules

Portrait: HUD on top, board fills the width minus the rail, rail on the trailing edge. Landscape and tablets: rail moves to the trailing side of the screen with the HUD, and the board is centred. Cell size = min(width / columns, height / rows), floored to whole pixels.

Game

Motion

Springs for things the player touches, linear for liquid, slow pulses for things that are waiting. Liquid progress is driven by the engine, never by an animator.

Try it

Reduced motion: springs become 160ms ease-out, pulses freeze at 60%, no shake, no droplet burst. Liquid fill is gameplay and is never reduced.
